# Datasets

IFC test models and their companion requirement artefacts (IDS, simplified BEP, ground truth) used by tests and the evaluation harness.

## Policy

Only two kinds of model may live here:

| Kind | Source | Licence | Location |
|---|---|---|---|
| **Synthetic** | Generated deterministically by `tests/evaluation/benchmark.py` with IfcOpenShell; benchmark output is regenerated on demand and ignored by Git | Repository licence (MIT) | `datasets/synthetic/generated/` (runtime output) |
| **Permitted** | Openly licensed sample files whose licence allows redistribution; the licence text and source URL must be recorded with each file | As stated per file in `datasets/permitted/LICENCES.md` | Not used by the current T-6 benchmark |

Never commit:

- real project models or anything derived from `hackathon-private/`;
- files larger than ~5 MB (the benchmark is designed to load in the browser in seconds);
- generated scratch outputs (`datasets/**/generated/` is git-ignored and the benchmark is regenerated by the evaluation runner).

Fixture IFC files are read-only (`C-04`). Produce variants by script, never by editing in place.

## Private local inputs

Real project models and documents belong in the ignored, owner-managed
`local-private/bim-models/` and `local-private/bim-documents/`, not in `datasets/` or tracked fixture
directories. The owner creates these folders locally; do not add placeholders. Private testing
evidence belongs in `local-private/test-results/`. These inputs are separate from the T-6 synthetic
benchmark and do not change its generation, evaluation or fixture policy.

Follow the inspection, transmission, publication and security/provenance review rules in
[AGENTS.md](../AGENTS.md). Local access does not authorise an LLM upload; public demonstration
templates must use synthetic or expressly redistributable data.

## Status

T-6 generates a synthetic IFC4 reference model, defective model, IDS, injection manifest,
independently checked ground truth, BEP and objective examples. Run
`python -m tests.evaluation.run_eval` from the repository root to regenerate the inputs and execute
the benchmark; see [docs/EVALUATION.md](../docs/EVALUATION.md) for the defect catalogue, measured
results and hashes. The generator does not modify the minimal IFC/IDS fixtures. An optional second
dataset using a permitted public IFC remains unresolved under [ADR-011](../docs/DECISIONS.md#adr-011-synthetic-benchmark-with-defect-injection) and OQ-03.
