# Datasets

IFC test models and their companion requirement artefacts (IDS, simplified BEP, ground truth) used by tests and the evaluation harness.

## Policy

Only two kinds of model may live here:

| Kind | Source | Licence | Location |
|---|---|---|---|
| **Synthetic** | Generated by `datasets/generate.py` (planned, Day 4) with `ifcopenshell.api`, then defect-injected by script; the generator is deterministic and its outputs are committed so the frontend and demo do not depend on Python | Repository licence (MIT) | `datasets/synthetic/` |
| **Permitted** | Openly licensed sample files whose licence allows redistribution; the licence text and source URL are recorded alongside the file | As stated per file in `datasets/permitted/LICENCES.md` | `datasets/permitted/` |

Never commit:

- real project models or anything derived from `hackathon-private/`;
- files larger than ~5 MB (the benchmark is designed to load in the browser in seconds);
- generated scratch outputs (`datasets/**/generated/` is git-ignored — the canonical benchmark is regenerated into `datasets/synthetic/` by the script).

Fixture IFC files are read-only (`C-04`). Produce variants by script, never by editing in place.

## Status

No datasets exist yet. The benchmark generator and defect catalogue are specified in [docs/EVALUATION.md §2](../docs/EVALUATION.md#2-benchmark-design); the choice between a synthetic-only benchmark and an additional permitted sample is an open decision (ADR-011, OQ-03).
