# Duplex Apartment — Multidisciplinary BIM Example

## Intended IFC inputs

- `Duplex_A_20110907.ifc`
- `Duplex_Electrical_20121207.ifc`
- `Duplex_M_20111024_ROOMS_AND_SPACES.ifc`
- `Duplex_MEP_20110907.ifc`
- `Duplex_Plumbing_20121113.ifc`

## Intended uses

- Architectural model and IFC element/property inspection.
- Information-quality validation against an applicable, separately prepared IDS.
- Future multidisciplinary model federation and geometric coordination testing.

The current application handles one model per session. Federation and geometric clash detection
are not implemented.
