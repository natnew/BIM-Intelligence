# Molio — IFC Information and Reference Example


## Intended IFC input

This collection records an intended IFC input for information and reference exploration.

## Intended input


- `Molio_with_URIs.ifc`

## Intended uses

- IFC metadata and property inspection.
- Reference and URI-related data exploration, where present.
- Information-quality checks against applicable, explicitly defined requirements.
