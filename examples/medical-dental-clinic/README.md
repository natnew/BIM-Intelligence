# Medical Dental Clinic — Architectural BIM Example

## Intended IFC inputs

- `Clinic_Architectural.ifc`
- `Clinic_Electrical.ifc`
- `Clinic_HVAC.ifc`
- `Clinic_Plumbing.ifc`
- `Clinic_Structural.ifc`

## Intended uses

- Geometry and element inspection.
- Model navigation and rendering assessment.
- Project-specific IDS testing against separately prepared, applicable requirements.
- Future multidisciplinary coordination testing.

Federation and geometric clash detection are not implemented in the current application.
